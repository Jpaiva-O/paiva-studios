# Paiva Studios

The photography and video portfolio for **João Oliveira**, published at https://jpaiva-o.github.io/paiva-studios/

Built as a dependency-free static site: HTML, CSS and vanilla JS. Images are cached locally in `assets/`.

## Files

- `index.html` — page structure, SEO/Open Graph metadata
- `styles.css` — design tokens, responsive layout, motion keyframes
- `script.js` — gallery, filters, lightbox, particles, theme toggle
- `DESIGN.md` — design identity and motion notes
- `assets/` — profile image, gallery images, favicon
- `data/posts.json` — cleaned archive export

## Updates

Edit the files on `main`; GitHub Pages republishes automatically. To update the archive, replace the images in `assets/` and edit the gallery data in `script.js`.
